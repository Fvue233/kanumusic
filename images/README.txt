# 图片资源说明

本文件夹用于存放游戏中的图标和背景图。

## 推荐准备的图片资源

1. **唱片图标**
   - 文件：record.png / record.svg
   - 用途：唱片显示
   - 建议尺寸：150x150像素

2. **游戏背景图**
   - 文件：background.jpg
   - 用途：游戏整体背景
   - 建议尺寸：1920x1080像素，高质量

3. **按钮图标**
   - 文件：buttons.png（或单独的按钮图标文件）
   - 用途：功能按钮
   - 建议尺寸：根据按钮大小调整

4. **生命图标**
   - 文件：life.png
   - 用途：显示生命值
   - 建议尺寸：30x30像素

## 图片格式建议

- 对于图标：优先使用SVG格式（可缩放，清晰度高）或PNG格式（透明度支持）
- 对于背景图：使用JPG格式，平衡质量和文件大小

## 图片资源要求

- 确保图片资源的尺寸适当，不要过大影响加载速度
- 图标类资源建议使用透明背景
- 背景图可以使用渐变或纹理，增强游戏氛围
